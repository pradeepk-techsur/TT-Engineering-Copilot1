```typescript
// Revoke UPDATE/DELETE on audit_history from app_role (append-only enforcement)
await db.execute(sql`
  REVOKE UPDATE, DELETE ON audit_history FROM app_role;
`);
```

Place this immediately after the closing of the existing `DO $$ ... $$` block and before the `console.log('Seed complete...')` line. The full ordering should be:
1. Upsert project row (onConflictDoNothing)
2. Insert 10 phase_states rows (onConflictDoNothing)
3. CREATE ROLE app_role if not exists (DO block)
4. **NEW**: REVOKE UPDATE, DELETE ON audit_history FROM app_role
5. console.log + process.exit(0)

The REVOKE is idempotent — revoking a privilege that was never granted is a no-op in PostgreSQL (does not throw; issues a NOTICE). This is safe to re-run on every container boot.

**`src/app/phase/[id]/page.tsx`** — dynamic route; reads `params.id` and passes as `phaseId` to AppShell so Breadcrumb renders `EV-INV-800 > Phase N: [Name]`:
```tsx
import { AppShell } from '@/components/layout/AppShell';
import { PHASE_CONFIG_MAP } from '@/shared/constants/phaseConfig';

interface Props {
  params: Promise<{ id: string }>;
}

export default async function PhaseWorkspacePage({ params }: Props) {
  const { id } = await params;
  const phaseId = parseInt(id, 10);
  const config = PHASE_CONFIG_MAP[phaseId as keyof typeof PHASE_CONFIG_MAP];
  const phaseName = config?.phaseName ?? `Phase ${phaseId}`;

  return (
    <AppShell phaseId={phaseId}>
      <div className="space-y-4">
        <h1 className="text-2xl font-bold text-[var(--color-text-primary)]">
          Phase {phaseId}: {phaseName}
        </h1>
        <p className="text-sm text-[var(--color-text-muted)]">
          Phase Workspace — available in a later build phase.
        </p>
      </div>
    </AppShell>
  );
}

export function generateStaticParams() {
  return Array.from({ length: 10 }, (_, i) => ({ id: String(i) }));
}
```
