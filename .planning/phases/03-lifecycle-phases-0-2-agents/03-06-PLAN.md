  <action>
Create `src/components/phase/OutputsPanel.tsx` as a `'use client'` component.

The component polls `GET /api/phases/{phaseId}/outputs` with SWR every 3000ms and renders the live artifact list. The outputs API response shape (from `src/app/api/phases/0/outputs/route.ts`) is:

```typescript
{
  phaseId: number;
  phaseState: string | undefined;  // e.g. 'AwaitingGate', 'AwaitingInputs', 'Processing'
  gateState: string | undefined;
  aiRecommendation: object | undefined;
  outputs: Array<{
    outputId: string;
    projectId: string;
    phaseId: number;
    outputName: string;
    artifactType: string;        // 'XLSX' | 'DOCX' | 'PDF'
    sizeGuidance: string;
    artifactId: string | null;
    versionRef: string;
    approvalStatus: string;      // 'Pending' | 'AwaitingReview' | 'Approved'
    reviewRequired: boolean;
    approvedBy: string | null;
    approvedAt: string | null;
  }>;
}
```

Rendering rules:
- `outputs.length === 0` → show a single row: `<span data-testid="outputs-pending">Pending phase execution</span>` (one row per expected output is NOT needed — just show one "Pending" message)
- `outputs.length > 0` → for each output row render a `<div data-testid="output-row">` containing:
  - `outputName` (e.g. "Opportunity Summary and Bid/No-Bid Recommendation")
  - `artifactType` badge (e.g. "XLSX", "DOCX")
  - `approvalStatus` as a muted label
  - A download `<a>` link to `/api/artifacts/{artifactId}/download` when `artifactId` is non-null; otherwise show "Processing…"
  - **`data-testid="output-row"` is required on the row container** — the SWR-polling Playwright test locates rows by this testid to prove real DB data reached the DOM
- While SWR is loading (no data yet): render `<div data-testid="outputs-loading">Loading outputs…</div>`

Style using the same Tailwind + CSS variable patterns as `InputReadinessPanel.tsx`:
- Row container: `flex items-center justify-between text-sm py-2 border-b border-[var(--color-border)]/50 last:border-0`
- Badge: `text-xs px-1.5 py-0.5 rounded bg-[var(--color-border)] text-[var(--color-text-muted)]`
- Download link: `text-xs underline text-blue-400 hover:text-blue-300`

| T-03-02 | Tampering | `OutputsPanel` — constructs `/api/artifacts/{artifactId}/download` href from API response | mitigate | `artifactId` is inserted into an `href` attribute string only, never into `innerHTML` or `dangerouslySetInnerHTML`. | T-03-03 | Information disclosure | `GET /api/phases/{id}/outputs` — returns phase state and output records | accept | No authentication in Phase 3 POC (pre-auth phase). All data is synthetic/POC. Accepted per project scope — real auth is a later-phase concern. Residual risk owned by project scope decision. |
